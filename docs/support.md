## 💬 Community Discord

Join our official Discord server for real-time support, feature requests, and to share what you're building!

[**Join the ACHIEVE PRO Discord ➔**](https://discord.gg/example)

**What you'll find:**
- `#announcements` - Updates and new release notes
- `#support` - Ask questions and get help from our team and other developers
- `#showcase` - Show off your UI designs and custom implementations

## 📧 Email Support

For private inquiries, licensing questions, or priority support, please email us directly:

**Support Email:** [support@example.com](mailto:support@example.com)

When emailing for support, please include:
1. Your Unity Asset Store Invoice Number
2. Unity Version (e.g. `2022.3.5f1`)
3. ACHIEVE PRO Version (e.g. `v1.2.0`)
4. A clear description of the issue or question

## 🐛 Bug Reports

If you've encountered a bug, the fastest way to get it resolved is to submit an issue on our private GitHub repository (access provided upon verification in Discord) or via email.

Please provide:
- Steps to reproduce the bug
- Expected behavior vs. actual behavior
- Relevant error logs from the Unity Console
- Screenshots or video clips (if visual)

## 💡 Feature Requests

We are actively developing ACHIEVE PRO based on community feedback. If you have an idea for a new feature, adapter, or UI component, let us know in the `#feature-requests` Discord channel!
