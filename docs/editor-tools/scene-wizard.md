## 🛠️ Wizard Configurations

1. **Toast Position Anchor**:
   - `Top Right`
   - `Top Center`
   - `Bottom Right`
   - `Bottom Center`
   - `Top Left`
   - `Bottom Left`
2. **Active Theme Selection**: Select from Cyberpunk, Fantasy RPG, Console Modern, or your custom theme asset.
3. **Include Interactive Test Rig**: If checked, spawns on-screen UI buttons for testing unlocks, progress, and save data resets in Play Mode.

Click **"⚡ Generate Setup in Active Scene"** to complete setup in under 1 second!
