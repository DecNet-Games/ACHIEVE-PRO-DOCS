# Achievement Studio Hub Window
{: .no_toc }

The primary workspace for authoring, filtering, inspecting, and managing all achievement ScriptableObjects in your project.

## 🏆 Opening the Studio Hub

- **Top Menu**: `Tools > Achievement System Pro > Achievement Studio Hub`
- **Keyboard Shortcut**: `Ctrl + Shift + A` (Windows) / `Cmd + Shift + A` (macOS)

---

## 📊 Live Telemetry Ribbon

The top header bar delivers immediate statistical telemetry:
- **Total Achievement Count**: Number of registered achievements in the project.
- **Gamerscore Total (+G)**: Total cumulative points available to earn.
- **Play Mode Earned Score**: Real-time points earned in current play session.
- **Rarity Distribution Spectrum**: A multi-colored spectrum bar visualizing the percentage breakdown of Common, Uncommon, Rare, Epic, and Legendary achievements.

---

## 🔍 Instant Search & Multi-Level Filtering

- **Text Search**: Real-time filtering by title, internal ID, description, or tag.
- **Category Tabs**: Switch between `All`, `General`, `Combat`, `Quests`, `Secret`, etc.
- **Rarity Filter Dropdown**: Narrow down achievements by rarity tier.
- **Batch Selection**: Bulk select achievements for batch deletion or category assignment.

---

## 🖼️ Live In-Editor Toast Preview

Selecting any achievement in the sidebar immediately renders a live preview of how the toast will appear in-game, including glowing borders, Gamerscore badges, icons, and progress meters.
